FAST REPLACE IN CURSOR
- Open the folder in Cursor.
- Press Cmd+Shift+F on Mac.
- Search: [DEVELOPER NAME]
- Replace All with your legal seller/developer name.
- Search: [SUPPORT EMAIL]
- Replace All with your support email.
- Save all files.

GITHUB PAGES
1. Create a public GitHub repository named:
   unlock-with-prayer-site

2. Upload all five files to the repository root.

3. Open:
   Repository Settings → Pages

4. Under Build and deployment:
   Source: Deploy from a branch
   Branch: main
   Folder: / (root)
   Click Save.

5. Wait a few minutes. GitHub will show your public URL, usually:
   https://YOUR-GITHUB-USERNAME.github.io/unlock-with-prayer-site/
